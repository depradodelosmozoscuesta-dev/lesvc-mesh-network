# lesvc-mesh-network

**LESVC Mesh Audio** – app Android para enviar y recibir mensajes de texto por
sonido entre móviles, sin internet ni cobertura. Motor: [ggwave](https://github.com/ggerganov/ggwave)
(MIT, versión fijada `ggwave-v0.4.3`) vía JNI.

- Texto UTF-8 completo (ñ, tildes, ¿¡), troceo automático de mensajes largos
- Modos audible normal / rápido / muy rápido y ultrasonido (experimental)
- Escucha continua con historial y hora; el silencio no genera texto
